🌍 Configuración CORS

Orígenes Específicos

Nunca uses wildcards (*) en producción. Especifica orígenes exactos.

services.AddCors(options => {
options.AddPolicy("Production", builder => {
builder.WithOrigins("https://myapp.com")
.WithMethods("GET", "POST", "PUT", "DELETE")
.AllowCredentials();
});
});
Headers Permitidos

Restringe los headers permitidos a los estrictamente necesarios.

.WithHeaders("Content-Type", "Authorization", "X-Requested-With")

🛡️ Headers de Seguridad

Headers Esenciales

Implementa headers de seguridad críticos para proteger la aplicación.

app.Use(async (context, next) => {
context.Response.Headers.Add("X-Content-Type-Options", "nosniff");
context.Response.Headers.Add("X-Frame-Options", "DENY");
context.Response.Headers.Add("X-XSS-Protection", "1; mode=block");
await next();
});

📝 Resumen de Integración Segura

🔒 Autenticación
  • JWT con expiración corta (15-30 min)
  • Refresh tokens para renovación
  • Logout en ambos extremos
  • Validación en cada request
🛡️ Autorización
  • Verificación basada en recursos
  • Principio de menor privilegio
  • Claims específicos por función
  • Validación de ownership
🌐 Comunicación
  • HTTPS obligatorio siempre
  • CORS restrictivo y específico
  • Headers de seguridad completos
  • Validación de certificados
🔍 Monitoreo
  • Logs de seguridad detallados
  • Detección de anomalías
  • Alertas de seguridad
  • Auditoría de accesos
