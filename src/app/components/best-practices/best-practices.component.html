🔧 Implementación en Angular

// En tu servidor (Express.js ejemplo)
app.use((req, res, next) => {
  res.setHeader(
    'Content-Security-Policy',
    "default-src 'self'; " +
    "script-src 'self' 'unsafe-inline'; " +
    "style-src 'self' 'unsafe-inline'; " +
    "img-src 'self' data: https:;"
  );
  next();
});

// O en el index.html
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self'; script-src 'self'">

  • ✅ Validar todas las entradas del usuario

📚 Guía de Uso Seguro del DomSanitizer

✅ Cuándo SÍ usar DomSanitizer:

  • Con contenido HTML de fuentes completamente confiables
  • Después de validación exhaustiva del contenido
  • Con URLs de dominios en lista blanca
  • Para contenido estático conocido y seguro
  • En casos donde tienes control total del contenido

❌ Cuándo NO usar DomSanitizer:

  • Con entrada directa del usuario sin validar
  • Con contenido de fuentes externas no confiables
  • Como primera línea de defensa
  • Sin entender completamente el contenido
  • Para "arreglar rápido" problemas de seguridad

💻 Patrón Recomendado:

// 1. Validar contenido
if (!this.isContentSafe(userContent)) {{ '{' }}
  throw new Error('Contenido no seguro');
