Configuraciones de Trusted Types para diferentes escenarios de aplicaciones Angular

📋 ¿Qué son los Trusted Types?

Los Trusted Types son una característica del navegador que ayuda a prevenir ataques XSS requiriendo que solo valores "confiables" se asignen a propiedades DOM peligrosas.

  • Operan a nivel DOM - la defensa más efectiva
  • No pueden ser bypaseados por APIs de bajo nivel

🔐 Configuración XSRF/CSRF en Angular

HttpClient incluye protección automática contra ataques Cross-Site Request Forgery

🔄 Cómo Funciona

  1. El servidor establece una cookie con token XSRF
  2. Angular lee la cookie automáticamente
  3. El token se envía como header en requests mutativos
  4. El servidor valida que cookie y header coincidan

⚠️ Importante

HttpClient solo maneja la mitad cliente de la protección XSRF. El servidor debe:

  • Establecer la cookie XSRF-TOKEN
  • Validar el header X-XSRF-TOKEN en requests
  • Generar tokens únicos y verificables

🔒 Seguridad del Nonce

  • Debe ser único por request
  • No debe ser predecible o adivinable
  • Mínimo 128 bits de entropía
  • Regenerar en cada respuesta del servidor
