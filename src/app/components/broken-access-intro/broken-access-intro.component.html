🚪 A01: Broken Access Control

Control de acceso roto en aplicaciones Angular

⚠️ Vulnerabilidad #1 del OWASP Top 10

¿Qué es Broken Access Control?

El Control de Acceso Roto ocurre cuando las aplicaciones no aplican correctamente las restricciones sobre lo que los usuarios autenticados pueden hacer. En Angular, esto significa que los guards, interceptors y validaciones de permisos no funcionan como deberían.

🎯 Puntos Clave en Angular:

  • Route Guards que solo verifican el lado cliente
  • API Endpoints sin validación de permisos
  • UI Controls ocultos pero funcionales
  • JWT Claims no validados en el servidor
  • CORS Settings demasiado permisivos

🅰️ Consideraciones Específicas de Angular

🛡️
Route Guards

Los guards CanActivate, CanLoad solo funcionan en el cliente. Siempre validar en el servidor.

🔄
Interceptors

Los HTTP interceptors pueden agregar tokens, pero el servidor debe validar todas las peticiones.

🎭
Directivas Estructurales

*ngIf solo oculta elementos. No es una medida de seguridad real.
